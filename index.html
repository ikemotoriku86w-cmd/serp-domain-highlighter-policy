SERP Domain Highlighter プライバシーポリシー

最終更新日: 2026-07-31

本拡張機能「SERP Domain Highlighter」(以下、本拡張) のプライバシーポリシーです。本拡張をインストール・利用された時点で、本ポリシーに同意したものとみなします。

1. 取得・利用するデータ

本拡張が取り扱うデータは、ユーザーが自身で入力する以下の設定値のみです。

  • ハイライト対象として登録したドメイン
  • 各ドメインに割り当てたハイライト色
  • プリセット (ドメインと色のセット) の名前
  • ハイライト機能の有効/無効の設定

本拡張は、閲覧履歴、検索キーワード、検索結果の内容、個人情報などを取得・記録することは一切ありません。

2. データの保存

上記の設定値は、ブラウザの chrome.storage.sync 機能を使い、ユーザーご自身の Chrome プロファイル内 (および同一 Google アカウントで同期された Chrome 間) にのみ保存されます。本拡張の開発者を含む第三者がこれらのデータにアクセスすることはありません。

3. データの送信先

本拡張は、いかなるデータも外部サーバーへ送信しません。開発者のサーバー、解析サービス、広告ネットワーク等との通信は一切行いません。本拡張の動作はすべてユーザーのブラウザ内で完結します。

4. 動作するページ

本拡張のコンテンツスクリプトは、Google 検索の検索結果ページ (google.com / google.co.jp の /search) でのみ動作し、登録されたドメインに一致する検索結果の表示スタイルを変更 (ハイライト表示) します。ページ内容の収集や書き換え、他のウェブサイトへのアクセスは行いません。

5. CSV インポート / エクスポートについて

設定の CSV インポート / エクスポート機能は、ユーザーのローカル環境でのファイル読み書きのみで完結します。ファイルの内容が外部へ送信されることはありません。

6. データの第三者提供・販売

本拡張は、ユーザーデータを第三者に販売、貸与、譲渡することはありません。また、信用力判定や融資判定の目的で使用または転送することもありません。本拡張の単一目的 (Google 検索結果のハイライト表示) 以外の用途でユーザーデータを使用することはありません。

7. ユーザーによるデータ削除

chrome.storage.sync に保存された設定値は、Chrome の拡張機能管理画面から本拡張をアンインストールすることで削除されます。特定のドメインやプリセットのみを削除したい場合は、本拡張のポップアップ画面から削除してください。

8. お問い合わせ

本ポリシーや本拡張機能に関するお問い合わせは、Chrome Web Store のサポートタブまたは公開時に記載するメールアドレスまでご連絡ください。

9. 本ポリシーの変更

本ポリシーは予告なく変更される場合があります。変更後は本ページの最終更新日が更新されます。
