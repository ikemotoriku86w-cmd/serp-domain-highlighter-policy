SERP Toolkit プライバシーポリシー

最終更新日: 2026-09-11

本拡張機能「SERP Toolkit」(旧称: SERP Domain Highlighter。以下、本拡張) のプライバシーポリシーです。本拡張をインストール・利用された時点で、本ポリシーに同意したものとみなします。

1. 取得・利用するデータ

本拡張が取り扱うデータは、次の3種類のみです。

(1) ユーザーが自身で入力する設定値

  • ハイライト対象として登録したドメイン
  • 各ドメインに割り当てたハイライト色
  • プリセット (ドメインと色のセット) の名前
  • ハイライト機能の有効/無効の設定

(2) 表示中の検索結果ページ上のリンク URL (URL コピー機能)

ユーザーが「オーガニック URL をコピー」機能 (ポップアップのボタンまたはキーボードショートカット) を実行したときに限り、そのとき表示している Google 検索結果ページから検索結果のリンク URL を読み取り、ユーザーご自身のクリップボードへ書き込みます。読み取った URL はクリップボードへの書き込みにのみ使用され、本拡張の開発者や第三者へ送信されることはありません。本拡張はクリップボードへの書き込みのみを行い、クリップボードの内容を読み取ることはありません。

(3) Google への検索結果リンクの照会 (URL コピー機能、v2.2.0 以降)

Google 検索結果のリンクが、リンク先 URL を含まない Google の中継リンク (/goto?url=... 形式) になっている場合、ページ内の情報だけではリンク先 URL を取得できません。この場合に限り、ユーザーが URL コピー機能を実行したときに、表示中の検索結果ページと同じ Google のオリジンに対して、その中継リンクのリダイレクト先 URL を照会します。照会は次の条件で行います。

  • 照会するのは、ユーザーが URL コピー機能を実行したときだけです。ページの読み込みやハイライト表示の更新だけでは照会しません。
  • 照会先は表示中の Google 検索結果ページと同じ Google のオリジンのみで、リンク先のウェブサイトにはアクセスしません。
  • 照会には Cookie と Referer を付与しません。ただし、照会先は Google であるため、Google 側でアクセスが記録される可能性があります。
  • 照会した中継リンクと取得したリンク先 URL は、タブごとに最大 100 件・有効期限 60 秒のセッション内一時キャッシュとして保持し、有効期限切れ・タブを閉じたとき・ブラウザの終了時に削除します。

本拡張は、閲覧履歴、検索キーワード、個人情報などを取得・記録・蓄積することは一切ありません。

2. データの保存

上記 (1) の設定値は、ブラウザの chrome.storage.sync 機能を使い、ユーザーご自身の Chrome プロファイル内 (および同一 Google アカウントで同期された Chrome 間) にのみ保存されます。本拡張の開発者を含む第三者がこれらのデータにアクセスすることはありません。上記 (2) のリンク URL は保存されません。上記 (3) の照会結果は、ブラウザの chrome.storage.session 機能によるセッション内の一時キャッシュにのみ保持され、永続的なストレージや同期ストレージには保存されません。

3. データの送信先

本拡張は、開発者のサーバー、解析サービス、広告ネットワーク等へデータを送信することは一切ありません。本拡張がブラウザの外部と通信するのは、上記 1-(3) の Google への照会のみで、その際に送信されるのは表示中の検索結果ページに含まれる Google の中継リンクの情報だけです。設定値や取得した URL を開発者や第三者に送信することはありません。

4. 動作するページ

本拡張のコンテンツスクリプトは、Google 検索の検索結果ページ (google.com / google.co.jp の /search) でのみ動作し、登録されたドメインに一致する検索結果の表示スタイルの変更 (ハイライト表示) と、ユーザー操作時の検索結果リンク URL の読み取り (URL コピー機能) を行います。それ以外のページ内容の収集や書き換えは行いません。上記 1-(3) の Google への照会を除き、他のウェブサイトへのアクセスは行いません。

5. 使用する権限

  • storage: 上記 1-(1) の設定値を保存するために使用します。
  • clipboardWrite: URL コピー機能で、収集した URL の一覧をユーザーのクリップボードへ書き込むために使用します。クリップボードの読み取りは行いません。
  • webRequest: URL コピー機能で、上記 1-(3) の照会に対する Google からのリダイレクト応答 (リダイレクト先 URL) を観測するためにのみ使用します。通信内容の変更や遮断は行いません。ユーザーが通常のクリックで開いたリンクや、コピー対象として登録していないタブの通信は記録しません。
  • activeTab: ユーザーがポップアップを開いた、またはキーボードショートカットを実行したときに限り、そのタブの Google 検索結果ページに対する一時的なアクセス権を得るために使用します。恒久的なホスト権限は使用しません。
  • ホスト権限 (Google 検索結果ページ): ハイライト表示と URL 収集のために、検索結果ページの表示内容を読み取るために使用します。

6. CSV インポート / エクスポートについて

設定の CSV インポート / エクスポート機能は、ユーザーのローカル環境でのファイル読み書きのみで完結します。ファイルの内容が外部へ送信されることはありません。

7. データの第三者提供・販売

本拡張は、ユーザーデータを第三者に販売、貸与、譲渡することはありません。また、信用力判定や融資判定の目的で使用または転送することもありません。本拡張の単一目的 (Google 検索結果のハイライト表示およびオーガニック検索結果 URL のコピー) 以外の用途でユーザーデータを使用することはありません。

8. ユーザーによるデータ削除

chrome.storage.sync に保存された設定値は、Chrome の拡張機能管理画面から本拡張をアンインストールすることで削除されます。特定のドメインやプリセットのみを削除したい場合は、本拡張のポップアップ画面から削除してください。上記 1-(3) のセッション内一時キャッシュは、有効期限切れ・タブを閉じる・ブラウザを終了するのいずれかで自動的に削除されます。

9. お問い合わせ

本ポリシーや本拡張機能に関するお問い合わせは、Chrome Web Store のサポートタブまたは公開時に記載するメールアドレスまでご連絡ください。

10. 本ポリシーの変更

本ポリシーは予告なく変更される場合があります。変更後は本ページの最終更新日が更新されます。

  • 2026-09-11: v2.2.0 で、リンク先 URL を含まない Google の中継リンクに対応するため、URL コピー実行時に限り Google へリダイレクト先を照会する動作と、そのセッション内一時キャッシュ、webRequest / activeTab 権限に関する記載を追加。
  • 2026-08-31: 拡張機能名を SERP Toolkit に変更。オーガニック URL コピー機能の追加に伴い、リンク URL の取り扱いと clipboardWrite 権限に関する記載を追加。
  • 2026-07-31: 初版。
